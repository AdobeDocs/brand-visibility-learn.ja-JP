# Bing ウェブマスターツール AI パフォーマンスレポート

Microsoftが新たにリリースしたBing Web マスターツールのAI パフォーマンスレポートでは、AIが回答のソースとしてコンテンツを引用する頻度や、生成エンジン最適化（GEO）によるコンテンツの意味を追跡する方法をご紹介します。

## この動画は誰のためのものでしょうか？

* 管理者、リーダー、ユーザーは、検索とAIのエクスペリエンスをまたいでコンテンツの可視性を追跡します
* 地域とAI主導の発見に焦点を当てたマーケターとコンテンツチーム

## ビデオコンテンツ

このビデオでは、次のことを説明します。

* AI パフォーマンスレポートで、既存のBing Web マスターツールにAI可視化分析レイヤーを追加する方法
* 合計引用、平均引用ページ、ページレベルの引用データなど、レポートする主要指標
* 引用の背後にあるファンアウトのクエリと、その背後にあるプロンプトを公開しない理由をレポートで明らかにする方法
* 引用データとクリック数、インプレッション数、ランクの従来の検索パフォーマンスレポートの違い
* 位置情報がAdobe Brand Visibilityを補完する理由

>[!NOTE]
>現在、AI パフォーマンスレポートでは、Bing Copilotの引用とAIの要約のみが対象となっています。 ChatGPTなどの他のAI アシスタントはまだ含まれていません。
